# 제이비 스튜디오

벌 캐릭터와 함께 카드뉴스를 만들고, 문구·이미지·레이아웃을 바로 편집할 수 있는 정적 웹 앱입니다.

## 사용법

1. `dist/index.html`을 브라우저에서 열거나 정적 호스팅에 올립니다.
2. 이미지를 넣고 원하는 방향을 작성한 뒤 카드 장수를 선택합니다.
3. 생성된 카드의 글자를 더블클릭해 수정하고 PNG 또는 ZIP으로 저장합니다.

## GitHub Pages

저장소에 `index.html`, `app.css`, `app.js`, `bee-mascot.png` 등 `dist` 안의 파일을 올린 뒤, 저장소의 **Settings → Pages**에서 배포할 브랜치와 폴더를 선택하면 됩니다.

현재 문장 다듬기와 카드 구성은 별도 API 키 없이 브라우저에서 동작하는 로컬 규칙 기반 방식입니다.
