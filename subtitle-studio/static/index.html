자막 구간을 누르면 이 화면에 표시됩니다. 화면 비율과 줄바꿈을 확인하는 미리보기이며, 원본 영상에는 적용되지 않습니다.

기본 검사는 PC에서 띄어쓰기와 자주 틀리는 표기를 제안합니다. 의심 구절은 빨간색으로 표시됩니다. AI 정밀 검사는 별도 API 키가 필요하고 자막 문장만 전송합니다. 제안은 직접 선택해 적용합니다.
